## 💎 Recursos
- **29 Unfollowers Identificados**: Lista completa de quem você segue, mas não te segue de volta.
- **Filtros Inteligentes**: Separação entre Perfis Pessoais vs Páginas/Famosos.
- **Links Diretos**: Acesso rápido ao perfil de cada usuário no Instagram.
- **Copiar e Exportar**: Botão para copiar todos os `@` de uma vez e exportar dados em formato CSV.
- **Design System Linear / Sports Red**: 100% responsivo, modo escuro obsidian, tipografia Plus Jakarta Sans e JetBrains Mono.
